How Ravenhold works

Three AI agents answer incidents from one FalkorDB graph. The company map, their memory and the way they hand work to each other are all nodes and edges, so every answer can be checked and every lesson is kept.

The agents get their tools from Ravenhold's MCP server (a separate process over stdio); any MCP client, such as Claude Desktop, can use the same server. All demo data is synthetic.

How each agent works

Each agent has its own job and its own graph tools, which it discovers from the MCP server's tool list and calls over MCP. They never pass notes in memory: the Commander writes a task into the graph, a worker picks it up, and writes its result back.
